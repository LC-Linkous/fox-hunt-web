A browser front end for the Ham Radio Village DEF CON 34 fox — a Seeed XIAO ESP32-C3 driving a NiceRF SA868 radio module. With this project's firmware on it, the fox becomes a receiver you control from the page: tune 2 m or 70 cm, watch signal strength, scan channels, decode a fox's Morse ID and SSTV pictures from the audio, log it all. With transmit enabled in the firmware and a license, it keys, sends Morse, and runs as a beacon.

What the firmware can and cannot do

  • As downloaded it is receive-only. TX_ENABLED = False at the top of code.py; with it false nothing in the file can key the transmitter, and no license is needed to use it.
  • With TX_ENABLED = True the transmit commands exist, behind a stored callsign, per-session arming, and a timer on every key-down that the board enforces itself. It still boots in receive. A license is required.
  • The SA868 fitted (VHF, UHF or dual-band) is a setting kept on the board; the page's Module dropdown sets it once.
  • Signal strength is the module's RSSI byte, 0–255, uncalibrated: a relative "warmer / colder" instrument, not a dBm meter.
  • The audio decoders do not use the fox's microcontroller at all: a wire from the SA868's AF_OUT pad to a sound card gives the page the audio. See the README for the wiring.

What the page keeps, and what it asks for

  • Nothing leaves the browser. There is no server; the page is static files. Settings live in this browser's local storage. Logs exist only while the page is open unless you save them.
  • Microphone — asked for only when you start audio. The page asks for echo cancellation, automatic gain and noise suppression off (they ruin Morse timing and SSTV tones) and shows what the browser actually granted. Audio is decoded in memory and never stored; decoded text and pictures are saved only when you click Save.
  • Location — off by default. When on, a badge shows, the fix's accuracy and age are displayed, a fix older than 15 s is not used, and lat/lon/accuracy go into their own columns of the log.
  • Compass (bearing helper, a later version) — asked for only when you start a bearing capture.
  • USB serial — the browser's chooser shows the fox; the page refuses a device that does not answer like this firmware.
